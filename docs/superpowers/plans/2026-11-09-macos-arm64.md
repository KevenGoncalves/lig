# Apple Silicon macOS Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver Apple Silicon builds with working shell integration, installer/updater, and capability-gated zellij resurrection.
**Architecture:** Isolate process inspection behind native platform functions. Keep Linux argv mirroring; implement macOS explicit zellij metadata updates using the shared exclusion policy.
**Tech Stack:** Rust, libc/libproc, shell hooks, Python PTY tests, GitHub Actions.
**Spec:** ../specs/2026-11-09-macos-arm64-design.md

## Global Constraints

- macOS release target is aarch64-apple-darwin only; preserve existing Linux releases.
- Unsupported zellij disables resurrection only; report the limitation in doctor.
- Preserve exact argv and cwd; never resurrect excluded commands.
- No changes to user shell configuration and no publishing.

## Review Focus

- Exited/reused process IDs and unreadable process information fail safely (task 1).
- Empty arguments, whitespace, malformed sysctl buffers, and environment separation (task 1).
- Old/hung zellij and changing command state cannot block terminal input (task 2).
- Invalid checksums and unsupported architecture do not install a binary (task 3).
- Nested fish/zsh and cwd containing spaces retain normal shell behavior (tasks 1, 4).
